## 无密码问题

如果windows使用微软账号登录，并且开启了无密码，远程登陆时会有问题，因为远程登录需要密码，但是你的账号又没密码，远程登录无法使用第三方授权APP.
解决办法：
```
runas /u:MicrosoftAccount\username@example.com winver
```
把`username@example.com`替换成你的微软邮箱，这样就可以使用密码了。设置密码需要保持强度，不能太简单，强度取决于策略组的配置
